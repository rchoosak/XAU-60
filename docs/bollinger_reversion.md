# การวิเคราะห์กลยุทธ์ Bollinger Reversion อย่างละเอียด 📊🔁

กลยุทธ์ **`bollinger_reversion.py`** เป็นระบบสไตล์ **Mean Reversion (การวิ่งเข้าสู่ค่าเฉลี่ย)** ที่เกิดมาเพื่อจัดการกับกราฟประเภทผันผวนอยู่ในกรอบ (Sideways หรือ Ranging Market) โดยเฉพาะ ถือเป็นจิ๊กซอว์ชิ้นสุดท้ายที่เอามาอุดรอยรั่วเวลาที่ระบบเทรดตามเทรนด์ (Trend Breakout) หรือจับเบรกหลอก (CRT/SMC) นิ่งเงียบ

## 🧠 หลักการทำงาน (Logic) ของกลยุทธ์นี้

### 1. โครงสร้างตีกรอบการแกว่ง (Volatility Bands)
ระบบใช้ **Bollinger Bands** (ค่ามาตรฐาน Period 20, Deviation 2.0) มาทำหน้าที่เป็นรั้วไฟฟ้าสถิตคอยดักราคาทั้งบนและล่าง:
- รั้วบน (Upper Band) คือ โซน Overbought ตามสถิติ
- รั้วล่าง (Lower Band) คือ โซน Oversold ตามสถิติ
- เส้นแกนกลาง (Middle Band / SMA 20) คือ โซนค่าเฉลี่ยดุลยภาพของตลาด

### 2. จุดปะทะขอบและชี้วัด (Confluence Entry)
การชนขอบกรอบเฉยๆ ไม่เพียงพอ บอทจะใช้ **RSI (14)** มาเป็นสายสืบยืนยันอีกทาง:
- **ยิง BUY (Long):** 
  - ราคาหลุดทะลุหรือจิ้ม "รั้วล่าง" (Lower Band) ของ Bollinger Bands
  - RSI ถลำลงไปในแดน Oversold (ต่ำกว่า 30)
  - **แท่งเทียนปัจจุบันต้องม้วนตัว ปิดสูงกว่าราคาเปิด** (คอนเฟิร์มว่ามีแรงซื้อสวนแล้ว)
- **ยิง SELL (Short):**
  - ราคาพุ่งกระแทกหรือทะลุ "รั้วบน" (Upper Band)
  - RSI ทะยานเข้าไปในแดน Overbought (สูงกว่า 70)
  - **แท่งเทียนปัจจุบันต้องหัวทิ่ม ปิดต่ำกว่าราคาเปิด** (คอนเฟิร์มว่าโดนทุบแล้ว)

### 3. จุดทำกำไรยืดหยุ่น (Dynamic Target)
- **Stop Loss (SL):** ใช้แบบตายตัวเป็น Pips คงที่ (Fixed) เผื่อในกรณีฉุกเฉินกราฟเปลี่ยนเป็นเทรนด์แรงๆ พาทะลุกรอบไปเลย
- **Take Profit (TP) พิเศษ:** หากเปิดใช้งานโหมด `use_dynamic_tp: true` เป้า TP จะถูกขยับเกาะติดไปกับ **เส้นกลางของ Bollinger Bands (SMA 20)** เพราะในสภาวะ Sideways ราคาจะโดนสปริงกลับมาแตะเส้นกลางนี้เสมอ 
- *ถ้าเส้นกลางอยู่ใกล้จุดเข้าเกินไป (แคบกว่า 30 Pips) ระบบจะขยับไปใช้ TP ไกลแบบคงที่แทนเพื่อความคุ้มค่า*

## 🛠️ วิธีจูนนิ่ง (Tuning) ให้ทำกำไรบน XAUUSD (เจาะลึกไฟล์ `bollinger_reversion.yaml`)

เนื่องจากราคาตลาดทองคำสามารถเกิดอาการ "เลื้อยติดขอบ" (Riding the Bands) ได้ ซึ่งเป็นหายนะของสาย Mean Reversion เราจึงต้องจูน 3 จุดนี้อย่างระมัดระวัง:

### 1. ปรับ Time Filter (หนีทิ้งช่วงความผันผวนสูง)
สภาวะ Sideways สม่ำเสมอมักจะเกิดแค่ใน **ตลาดเอเชีย (เช้าไทยถึงบ่ายโมงไทย)** ควรปล่อยบอทตัวนี้ให้ออกล่าเหยื่อเฉพาะช่วงเวลานี้เท่านั้น
```yaml
session:
  use_time_filter: true
  start_hour: 2            # (00:00 UTC หรือ 07:00 นาฬิกาไทย)
  end_hour: 10             # (08:00 UTC หรือ 15:00 นาฬิกาไทย - หยุดก่อนตลาดลอนดอนสาดวอลลุ่ม)
```
- ถ้าตลาดยุโรปและอเมริกา (หลังบ่ายสอง-เที่ยงคืนไทย) มาถึง **เราไม่ควรให้บอทตัวนี้ทำงาน** (ปล่อยให้ 3 ตัวเก่งไปสู้) ดังนั้นตัวนี้ตั้ง Time Filter ให้แม่นที่สุด!

### 2. กรองการเด้งเข้ากลาง (Targeting the Middle)
ใช้โหมด `use_dynamic_tp` เพื่อเป้ากำไรที่แม่นยำสูง แต่ต้องมีระยะ SL ไว้กันเหนียวเสมอ

```yaml
risk:
  stop_loss_pips: 150.0      # ให้ระยะหายใจ 150 pips ในกรณีโดนแท่งเทียนหางยาวสวิงทุบ
  take_profit_pips: 300.0    # ค่านี้คือแผนสำรองในกรณีสมการเส้นกลางมันแคบเกินไป
  use_dynamic_tp: true       # อันนี้สำคัญมาก ต้องเป็น true! ให้บอททุบกำไรตอนเส้นแตะกึ่งกลาง (โคตรแม่นเรื่อง Win Rate)
```

### 3. ปรับ Timeframe เป็น M15
ระบบ Mean Reversion จะแม่นยำมากถ้ารอให้แท่งที่มีความน่าเชื่อถือปิดจบตัวลง
- **ไม่แนะนำ `M1` หรือ `M5`:** เพราะทองคำเวลามันวิ่งทะลุขอบล่างของ M5 มันมักจะลงไปอีกเป็นพรวน ทำให้เข้าซื้อสวนเร็วเกินไป (สวนรถไฟ)
- **ใช้ `timeframe: M15`** จะเป็นกรอบมาตรฐานที่สมบูรณ์แบบในการหาจุดเข้าของ Bollinger Bands + RSI ควบคู่ไปกับรอบ Asian Session ครับ

### 4. ตัวชี้วัดเสริม Bollinger (Std Dev & Period)
```yaml
parameters:
  bb_period: 20
  bb_std_dev: 2.0       # หากรู้สึกกราฟชนบ่อยแล้ว SL รัวๆ ให้ลองเพิ่มขอบความหนาเป็น 2.5 (จะเข้าเทรดยากขึ้นมาก แลกกับความชัวร์ร้อยเปอร์เซ็นต์)
  rsi_overbought: 70.0
  rsi_oversold: 30.0
```

---
**✨ สรุป:** ระบบ **Bollinger Reversion** คือผู้พิทักษ์ (Defender) ของพอร์ตคุณในยามที่กราฟน่าเบื่อ มันช่วยปั๊มแคชโฟลว์ช่วงเช้าตอนที่มนุษย์อย่างเรากำลังชงกาแฟ หากเซ็ต Time Filter ควบคุมมันให้ดีๆ จำกัดให้เทรดแค่ช่วงเอเชีย มันคือสุดยอดเครื่องผลิตกระแสเงินสดเลยครับ!
