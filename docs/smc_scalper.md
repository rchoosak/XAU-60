# การวิเคราะห์กลยุทธ์ SMC Scalper อย่างละเอียด 📉📈

กลยุทธ์ **`smc_scalper.py`** เป็นกลยุทธ์สายปิ้งย่าง (Scalper) แบบฉบับของ **Smart Money Concepts (SMC)** ของแท้ 💯% ที่ออกแบบมาเพื่อจับจังหวะการกลับตัวของเทรนด์ (Reversal/Pullback) จากรายใหญ่โดยเฉพาะ

## 🧠 หลักการทำงาน (Logic) ของกลยุทธ์นี้

### 1. โครงสร้างจุดตีกรอบ (Setup Detection)
ระบบจะสแกนหากราฟเพื่อหาคอนเฟิร์ม "การเสียทรง" ของฝั่งตรงข้ามก่อนเสมอ:
- **ยิง BUY (Long):** 
  - หาราคาเบรกทะลุทำลายฝั่งลง หรือ **Bullish CHoCH** (Change of Character)
  - ต้องมีช่องว่างราคา **Bullish FVG** (Fair Value Gap) เกิดขึ้นเพื่อยันราคาไว้
  - หากรอบออเดอร์สะสมเทขายรอดักอยู่ข้างบน หรือ **Bearish Order Block (OB)** เพื่อเอาไว้เป็นเป้าเล็งปิดทำกำไร (TP)
- **ยิง SELL (Short):**
  - หาราคาเบรกทะลุทำลายฝั่งขึ้น หรือ **Bearish CHoCH** 
  - ต้องมีช่องว่างราคา **Bearish FVG** เกิดขึ้นเพื่อกดราคาไว้
  - หากรอบออเดอร์สะสมซื้อรอดักอยู่ข้างล่าง หรือ **Bullish Order Block (OB)** เพื่อใช้เล็งปิดกำไร (TP)

### 2. จุดเข้าทำกำไร (Entry Point)
บอท **"จะไม่ไล่ราคาเด็ดขาด"** แต่จะรอให้ราคาย่อกลับมาทดสอบตรงเส้นกึ่งกลางของช่องว่าง FVG (Midline) เท่านั้น (ถ้าราคาอยู่ห่างจากกึ่งกลาง FVG เกิน 20 pips บอทจะไม่เข้าเด็ดขาด เพื่อรักษา Risk:Reward ที่ดีเอาไว้)

### 3. จุดยอมแพ้ และ ทำกำไร (Exit Strategy)
- **Stop Loss (SL):** ใช้ความผันผวนจริงของตลาดมาคำนวณผ่านอินดิเคเตอร์ **ATR (Average True Range)** โดยจะวางหนีจากจุดเข้าออกไป 2 เท่าของความแกว่ง (Multiplier = 2.0) ทำให้ปลอดภัยจากการโดนสะบัดกินไส้
- **Take Profit (TP):** ระบบนี้ใช้สูตรร้ายกาจระดับสถาบัน คือ **"เล็งเป้าก่อนถึง Order Block 10 Pips" (Front-running)** เพื่อชิงหนีเทขายทำกำไรก่อนที่รายใหญ่จะกระแทกราคาใส่โซน OB 
  *(คล้ายกับว่า ถ้ารู้ว่าจะมีกำแพงดักทุบที่ 2000 บอทจะรีบชิงปิดหนีที่ 1999 ก่อนทันที)*
  - 🔄 *กรณีที่ Order Block ให้ผลตอบแทนไม่คุ้มค่า (น้อยกว่า 1:1.5) บอทจะเปลี่ยนไปใช้ระบบ R:R คงที่ (ค่าเริ่มต้นคือ 1:2.0) แทนวนไป*

## 🛠️ วิธีจูนนิ่ง (Tuning) ให้ทำกำไรได้ดีที่สุด (ลงในไฟล์ `smc_scalper.yaml`)

มีจุดที่คุณควรนำไปปรับแก้และจูนในตั้งค่า `config/strategies/smc_scalper.yaml` เพื่อให้รันบนคู่ทองคำ (XAUUSD) ได้โหดที่สุดครับ:

### 1. ⚠️ ปรับแก้เวลาทำการ (Session Filter)
ค่าเริ่มต้นของโค้ดให้บอททำงานตั้งแต่ `start_hour: 8` ถึง `end_hour: 18` **(อ้างอิงตามเวลาโบรกเกอร์แบบ MT5 Server Time)**
- หากโบรกเกอร์คุณเป็น UTC+2/+3 ค่านี้จะตรงกับประมาณบ่ายสองโมง (14:00 น.) ถึงเที่ยงคืนไทย (00:00 น.) ซึ่งถือว่า **เวลาดีมาก** เพราะครอบคลุมตลาดยุโรปและอเมริกา แต่ถ้าอยากให้มันเทรดดุดันจนจบตลาดอเมริกา ให้เลื่อน `end_hour` ไปถึงช่วงตลาดยับวาย:

```yaml
session:
  trade_friday: false  # (แนะนำให้ปิดวันศุกร์หนี Non-Farm หรือข่าวสวิงนรก)
  start_hour: 9        # เริ่มสแกนตอนตลาดลอนดอนเปิด (14:00/15:00 น. ไทย)
  end_hour: 22         # สแกนลากยาวไปจนตลาดนิวยอร์กใกล้ปิด (ตี 3/ตี 4 ไทย)
```

### 2. โมดิฟาย SL กับ Trailing Stop
การเก็บสั้น (Scalping) ปล่อยให้ระยะหนี `ATR = 2.0` อาจจะทำให้ SL กว้างไปนิด ส่งผลให้เวลาเป้า TP ก็ตีกลับไปกว้างกว่าเดิมทำให้โดนยากขึ้น:
> **วิธีปรับ:** 

```yaml
parameters:
  choch_lookback: 50
  fvg_min_pips: 5.0
  ob_lookback: 20
  risk_reward: 2.0
  use_atr_sl: true
  atr_period: 14
  atr_multiplier: 1.5           # หด SL ให้น้อยลง จาก 2.0 มาเป็น 1.5 เพื่อให้ Ratio RR จุดปิดกำไรแคบลง ปิดจบไม้ได้ฉับไวกว่าเดิม
  trailing_stop: false          # ให้ปิด Trailing Stop ไว้สำหรับระบบนี้ เพราะเราอยากปล่อยราคาวิ่งไป "ชนเป้าหมาย Order Block" จริงๆ การเปิด Trailing ทิ้งระยะไกล 50 Pips สู้ปิดระบบทิ้งแล้วปล่อยให้ R:R ทำงานเต็มประสิทธิผลจะดีกว่า 
```

### 3. ตัวกรอง Timeframe
ใช้ **`M5`** (5 นาที) หรือ **`M15`** เป็นมาตรฐานหลัก
- สำหรับ SMC Scalper การย่อลงมาใช้ `timeframe: M5` จะสะใจและดุดันมาก เพราะเจอ CHoCH เร็ว ย่อเข้า FVG ไว และระยะ Order Block จะไม่ห่างไกลจนเกินไป 
- แต่ถ้ากลัวสัญญาณหลอก (Noise) ให้ใช้ `timeframe: M15` ตามมิตรภาพครับ 

---
**✨ สรุป:** ระบบ SMC Scalper จะโชว์ศักยภาพสูงสุดเมื่อกราฟมีการเบรกเทรนด์ ทำลายสวิง (CHoCH) และวิ่งห่างไปเพื่อสร้างช่องว่าง FVG การนำ Config ด้านบนไปจูนใน `smc_scalper.yaml` จะช่วยจำกัดการแพ้ และเพิ่มจุดความแม่นยำในการหนีตายทำกำไรก่อนรายใหญ่ให้พอร์ตคุณครับ!
